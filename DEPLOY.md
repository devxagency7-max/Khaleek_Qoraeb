# 🚀 Deploying to Vercel

Since your project is already on GitHub, deploying to Vercel is very easy and automatic.

1. **Go to Vercel:**
   - Visit [https://vercel.com/new](https://vercel.com/new).

2. **Import Git Repository:**
   - Select your GitHub account.
   - You should see `Khaleek_Qoraeb` in the list.
   - Click **Import**.

3. **Configure Project:**
   - **Framework Preset:** Other (or just leave default, it's a static site).
   - **Root Directory:** `./` (Default).
   - **Build Command:** (Leave empty).
   - **Output Directory:** (Leave empty).

4. **Deploy:**
   - Click **Deploy**.

🎉 **Done!**
Vercel will build your site and give you a live URL (e.g., `khaleek-qoraeb.vercel.app`).
Any time you push changes to GitHub (like we just did), Vercel will automatically update your site!
